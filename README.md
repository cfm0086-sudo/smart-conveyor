# smart-conveyor
Smart conveyor engineering project integrating mechanical design, manufacturing, data analytics and AI-assisted maintenance.
## 1. Project Objectives
Design a modular belt conveyor
Perform mechanical calculations
Create CAD models and technical drawings
Develop a manufacturing concept
Conduct PFMEA
Analyze simulated sensor and production data
Implement condition monitoring with Python
Develop an AI-assisted maintenance system
## 2. System Requirements
Conveyor length 1200mm
Belt width 300mm
Maximal load 20kg
Target belt speed 0.3 m/s
